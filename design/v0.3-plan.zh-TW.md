# v0.3 封裝與重連規格草案

使用者已接受 v0.2 核心與功能。此階段聚焦連線生命週期、Windows 管理介面、Android 連線介面與可安裝套件，不重新設計既有影像／筆資料協定。

## 現況缺口（已查閱原始碼）

- Windows 啟動先執行 ADB reverse；未接線時會失敗退出，尚無等待接線流程。
- 執行中只在影像不可用時補回 reverse；App 被關閉後不會由正常流程重新啟動。
- Android 的兩條 socket 已有重試；Activity 被銷毀或主機換了 session 後，單靠 socket 重試無法重新取得 session。
- 目前使用腳本啟動、依賴本機 SDK 的 ADB 路徑與 .NET Desktop Runtime，尚非完整桌面產品封裝。
- 現有測試證明規則修復與完整畫面重同步；不等同實體拔線、鎖屏與所有 App／主機生命週期均已驗證。

## 連線狀態與恢復

連線由 Windows 的單一管理程序負責，UI 不直接執行多組相互競爭的 ADB 操作。狀態與錯誤原因分開記錄，避免把所有問題都顯示為「斷線」。

| 狀態 | 行為與介面 |
|---|---|
| 已停止 | 不重試、不自動開啟平板 App；保留裝置偏好 |
| 等待裝置 | 尚未接線也保持執行；顯示「請接上平板」 |
| 需要 USB 授權 | 顯示解鎖／允許連線指引；不進入無限啟動迴圈 |
| 裝置暫不可用 | offline／命令逾時；有上限的退避重試，支援取消 |
| 建立連線 | 僅修復選定裝置的兩條規則，提供目前 session 給 App |
| 同步畫面 | 新連線從完整畫面開始；完整畫面 ACK 前不接受繪圖輸入 |
| 可以繪圖 | 影像與筆通道皆就緒；健康時不持續執行 ADB 命令 |
| 恢復中 | 釋放筆狀態、丟棄舊連線工作，等待裝置／App 回來後完整同步 |
| 需要協助 | App 遺失、版本不符或持續失敗；提供具體修復操作與匯出紀錄 |

影像與筆通道分別追蹤，任一缺失都不得以「可以繪圖」表示。恢復需有 session／generation 邊界，舊 socket、ACK、緩衝工作不能進入新 session。停止優先於重試；每個 ADB 操作都有逾時與取消，避免停止後又把 App 拉起來。

使用者按「開始」後，這次繪圖連線才具有恢復意圖。重新接線時允許一次自動啟動／更新 App session；失敗退避，不反覆搶前景。使用者按「停止」立即撤銷恢復意圖。鎖屏／授權頁由使用者處理，提示不代按。

Android 顯示最後畫面時需加斷線遮罩並停用筆輸入，避免誤認仍在繪圖。socket 重試在原 session 下進行；App 冷啟動沒有有效 session 時顯示「請在電腦開始連線」，由 Windows 正式開始流程提供新 session，不長期保存舊 token。

## 介面與封裝

SVG 是可編輯設計稿，不作為一整張圖片塞進產品。實作時使用原生控制項與共用配色／間距規格；文字、狀態與按鈕保留可存取性、縮放與鍵盤操作。

Windows：單一 GUI 程式、系統匣、裝置選擇、開始／停止、畫質預設、恢復提示；進階設定收納 renderer／window／日誌。關閉視窗與退出程式要明確區分。正常使用不需要終端機、SDK 路徑或 PowerShell。

Android：可從桌面啟動的連線首頁、清楚的連線狀態、重試入口、繪圖中的可收合小控制列；不佔用常駐大型側欄。未接線或 session 無效時不只顯示黑畫面。

套件目標：Windows 先交付完整可攜資料夾，再做安裝包／解除安裝；包含自足的執行環境及經核對授權、版本與雜湊的 ADB 依賴。APK 使用持續保管的簽章金鑰並支援原地升級。正常啟動只檢查版本，需要時才更新 APK。設定與日誌移到使用者應用程式資料目錄；移除程式時設定／日誌是否保留須明確。

正式對外散布前另行決定產品名稱、圖示、Windows 簽章與 Android 簽章管理。目前延續 USB Pen Display 名稱；SVG 畫質選項與互動尚未實作，不表示已交付功能。

## 實作順序與驗收

1. 先完成連線管理狀態機與錯誤分類，保留 v0.2 核心及量測介面。
2. 驗證未接線啟動、拔插、offline、授權待確認、鎖屏／解鎖、App 關閉／重開、主機重啟、重試中停止、重複啟動；不影響 Pixel。
3. 按 SVG 實作 Windows 面板／系統匣、Android 連線頁與小控制列。
4. 做自足套件、版本檢查／升級與解除安裝，再跑原有逐像素／有界管線回歸及實機恢復矩陣。

驗收必須區分可程式化故障注入與實體 USB 拔插。按住實體 S Pen 時拔線需人工確認沒有持續落筆；裝置回來後無須重啟電腦程式、完整同步完成才恢復輸入。持續失敗需顯示可操作原因，不能只無限旋轉。
